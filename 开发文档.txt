关键数据结构发现：
1. MechData : ClientConfigData (TypeDefIndex: 12406) - 单位战斗属性
   - life (int) - 生命值
   - damage (int) - 基础攻击力
   - moveSpeed (int) - 移动速度

   - rotateSpeed (FPoint) - 转动速度
   - mainSkillID (int) - 主技能ID（关联武器/攻击参数）
   - mechType (UnitType) - 单位类型
   - moveType (MechMoveType) - 移动类型
   - radius (FPoint) - 碰撞半径

2. CardData : ItemData (TypeDefIndex: 12323) - 单位卡片/UI数据
   - baseMoney (int) - 购买费用
   - maintenanceSupply (int) - 维护费/每回合
   - unlockPrice (int) - 解锁费用
   - mechID (int) - 单位ID
   - mechCount (int) - 每队数量
   - slotSize (int) - 部署槽大小
   - killBonus (List<int>) - 击杀奖励
   - technologies (List<int>) - 可用科技列表
   - defaultTechnologies (List<int>) - 默认科技

3. CardData Protobuf版本 (TypeDefIndex: 18334) - 网络传输用
   - LifeRating, DpsRating, SpeedRating, RangeRating (int) - 星级评分
   - BaseMoney, UnlockPrice, MechID, MechCount 等

4. AttributeUpgradeData : ConfigData (TypeDefIndex: 12318) - 升级属性
   - level (int) - 等级
   - lifeRating (FPoint) - HP倍率
   - damageRating (FPoint) - 伤害倍率

5. FightMech (TypeDefIndex: 15088) - 运行时战斗单位
   - 通过 IMechData data 和 IMechLevelData levelData 获取属性
   - GetBaseDamage(), GetMoveSpeed(), GetRadius(), GetSplashRange() 等访问方法

数据存储架构：
- MechData数值存储在Unity ScriptableObject中（二进制序列化）
- 游戏通过Addressables系统加载（common_assets_all.bundle, scuffle_assets_all.bundle等）
- Bundle解析：common_assets_all(89MB)仅含1个VideoClip+AssetBundle元数据

- 二进制搜索：scuffle_assets_all(596MB)中找到HP=277(280次)、ATK=79(107次)、Cost=100(98次)
  表明单位配置数据嵌入在大型bundle中，可通过完整解析提取

2026-07-28 对话记录 #5：运行时内存提取方案
----------------------------------------------------------------------
需求：
使用Cheat Engine从游戏内存中提取单位数据

技术分析：
- 游戏为IL2CPP编译，CE的Mono功能不可用
- Config类(GRSingletonMonoStatic<Config>)在启动时加载所有MechData/CardData
- ConfigDataContainer存储所有数据列表

关键数据结构（从dump.cs确认）：
```csharp
ConfigDataContainer:
  0x60: cardDatas (List<CardData>)    ← 卡片/UI数据
  0x68: mechDatas (List<MechData>)    ← 战斗属性
  0x80: attributeUpgradeDatas         ← 升级倍率

MechData:
  0x38: life (int)        ← HP
  0x3C: damage (int)      ← ATK
  0x40: moveSpeed (int)   ← 速度
  0x44: isFly (bool)
  0x64: mechType (UnitType enum)[0=Small,1=Medium,2=Huge]
  0x68: moveType (MechMoveType enum)[0=Normal,1=Underground,2=Cloak]

CardData:
  0x58: baseMoney (int)          ← 费用
  0x5C: maintenanceSupply (int)  ← 维护费
  0x80: mechID (int)            ← 单位ID
  0x84: mechCount (int)         ← 每队数量
  0x88: slotSize (int)          ← 部署槽
  0xA0: unlockPrice (int)       ← 解锁费

Unity IL2CPP List<T> 内部结构:
  0x00: _items (T[] ptr)
  0x10: _size (int32)
  0x14: _version (int32)

Unity IL2CPP String:
  0x10: length (int32)
  0x14: firstChar (UTF-16)
```

CE 操作步骤：
1. 附加到Mechabellum.exe
2. 在训练模式部署一个已知HP的单位（如Crawler HP=277）
3. 搜索4字节整数277 → 找到FightMech实例
4. FightMech+0xB0读取指针 → MechData地址
5. 搜索MechData指针值 → 定位mechDatas列表
6. 列表包含所有30+单位 → 一次性读取全部属性

工具尝试：
- pymem已安装（可读取进程内存）
- BepInEx v5.4.22已下载（但不支持IL2CPP，需要v6.x Bleeding Edge）
- 创建了extract_unit_data.py自动化脚本（框架已搭建，待完成定位逻辑）
